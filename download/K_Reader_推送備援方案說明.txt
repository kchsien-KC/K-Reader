K-Reader 上傳 GitHub——備援方案（自行推送）操作說明
=====================================================

搭配檔案：K_Reader_git_history.bundle（約 0.9 MB）
這個 bundle 內含 K-Reader 自 Stage 1 至 Stage 12 的完整開發歷史
（每一階段的 Kotlin 原始碼、版面配置、字串檔、交付 zip、驗證器與
README，共 17 個提交，含本說明檔）。在你自己的電腦上用它即可把
完整歷史推上你的 GitHub，全程不需要把任何權杖交給對話中的助手。

預估時間：10 分鐘。

---------------------------------------------------------------
第 1 步：下載檔案
---------------------------------------------------------------
在對話的檔案／下載區，點選 K_Reader_git_history.bundle 下載，
存到電腦預設的「下載（Downloads）」資料夾。

---------------------------------------------------------------
第 2 步：安裝 Git
---------------------------------------------------------------
Windows：到 https://git-scm.com/download/win 下載安裝檔，
安裝過程所有畫面都用預設值，一路按 Next 到完成。

Mac：到 https://git-scm.com/download/mac 安裝；
或在終端機輸入 git，依系統提示安裝 Command Line Tools。

---------------------------------------------------------------
第 3 步：在 GitHub 建立空的倉庫
---------------------------------------------------------------
1. 開啟 https://github.com/new （須先登入）
2. Repository name 填 k-reader （名稱可自訂）
3. 選 Public （公開，雲端編譯 GitHub Actions 免費；要私有也行）
4. 下方 Add a README / .gitignore / license 三個勾選【全部不要勾】
5. 按最下方綠色 Create repository
6. 記下倉庫網址，長得像 https://github.com/你的帳號/k-reader

---------------------------------------------------------------
第 4 步：開終端機，貼上指令
---------------------------------------------------------------
Windows：開始選單 → Git Bash
Mac：應用程式 → 終端機（Terminal）

把下面整串貼進去前，先將「你的帳號」換成你的 GitHub 帳號：

    cd ~/Downloads
    git clone K_Reader_git_history.bundle k-reader
    cd k-reader
    git remote set-url origin https://github.com/你的帳號/k-reader.git
    git push -u origin main

小技巧：在 Git Bash 視窗裡先輸入 git clone 加一個空格，
再把 bundle 檔案直接用滑鼠拖進視窗，會自動補完整路徑。

---------------------------------------------------------------
第 5 步：登入授權（推送時自動出現）
---------------------------------------------------------------
Windows：git push 時會自動跳出瀏覽器視窗，點
「Sign in with your browser」登入 GitHub 並按授權即完成，
不需要建立任何權杖（PAT）。帳號會存在 Windows 認證管理員，
日後 git push 不再詢問。

Mac：若終端機要求輸入 Username / Password——
  Username：你的 GitHub 帳號
  Password：不能填帳號密碼，必須填 PAT
  （到 https://github.com/settings/tokens 建一組，勾 repo 權限即可）
  更省事的替代：先安裝並登入 GitHub Desktop
  （https://desktop.github.com），終端機的 git 就能免權杖推送。

---------------------------------------------------------------
第 6 步：驗證
---------------------------------------------------------------
打開你的倉庫頁面 https://github.com/你的帳號/k-reader
上方點「17 commits」，應能看到從 Initial commit、Stage 1
到 Stage 12 的完整歷程，一次全在。

---------------------------------------------------------------
疑難排解
---------------------------------------------------------------
＊推送被拒（rejected / non-fast-forward）：
  多半是第 3 步不小心勾到了 README。在 k-reader 資料夾內執行：
      git push -u origin main --force
  （全新倉庫用 --force 無風險，只是覆蓋那個自動產生的 README）

＊提示找不到 bundle 檔：
  確認檔案真的在「下載」資料夾；或改用拖曳小技巧直接帶路徑。

＊clone 完不是 main 分支（正常不會發生，本 bundle 已含 HEAD）：
      git checkout main

＊其他錯誤：回到對話，把終端機顯示的錯誤訊息原樣貼上，我來解讀。
